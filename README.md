# ESC — Egypt Site Creation

Premium static agency website built with HTML, CSS and JavaScript.

## Files
- index.html
- css/style.css
- js/app.js
- robots.txt
- sitemap.xml
- manifest.webmanifest

## Before launch
1. Replace the placeholder WhatsApp number in `index.html`.
2. Replace the email address if needed.
3. Replace demo imagery with your own licensed images if you want full control.
4. Update the canonical domain if your final domain changes.
5. Test on mobile.
6. Deploy to your chosen static host and connect `egyptsitecreation.com`.

## Animation
The site uses GSAP and ScrollTrigger from jsDelivr. GSAP's official documentation describes GSAP as a framework-agnostic animation library and documents script-tag loading and ScrollTrigger plugins.


## Full Demo System
The `demos/` folder contains 10 complete, scrollable website concepts. The main ESC showcase includes an **Open full demo** button that follows the selected category.
